# たんたんご！ — 単語学習PWA（TOPIKⅡ 100語版）

同梱CSVは「第47回TOPIKⅡ_上級韓国語100単語(1).csv」（100語）に変更済みです。

iPhoneのSafariでホーム画面に追加できる、オフライン対応の単語学習アプリです。

## 公開方法（GitHub Pages）

1. ZIPを解凍。
2. GitHubの公開リポジトリで **Add file → Upload files** を開き、`Tantango_PWA` フォルダの**中身**をすべてアップロードしてコミット。`index.html` がリポジトリ直下にあることを確認。
3. **Settings → Pages → Build and deployment** を `Deploy from a branch`、`main`、`/(root)` に設定して保存。
4. 発行されたURLをiPhoneのSafariで開き、共有メニューから **ホーム画面に追加**。

**旧PWAを更新する場合：** 同じGitHubリポジトリのファイルを本ZIPの内容で上書きし、**元のGitHub PagesのURLを維持**してください。iPhoneに追加したローカルCSVは、同一オリジン・同じ保存領域であれば引き継げます。URLを変更したり、Webサイトのデータを消去したりすると、保存データを引き継げない場合があります。念のため元CSVを保管してください。

## 操作

- **ホーム**：セット名をタップ。CSV追加は `CSVを追加`。
- **一覧**：行を押すと画面下半分に単語・意味・例文・日本語訳。上半分はスクロールできます。
- **一覧の左端の☆**：押すと要復習に登録、もう一度で解除。登録はiPhone内に保存されます。
- **右上の☆**：要復習の単語だけを表示。再度押すと全件に戻ります。
- **右上のシャッフル**：CSV順 ⇔ ランダム順を切り替えます。
- **テスト**：単語をタップすると同じ位置で意味が現れ、下半分に例文・訳が出ます。もう一度タップで次の単語へ。解答表示中の右下☆で復習登録できます。
- **⭐絞り込み中のテスト**：復習対象の単語のみを、現在の表示順で出題します。テスト開始後に☆を解除してもその回の出題順は変わりません。

## CSV形式

UTF-8のCSV。1行目には必ず以下の見出しが必要です。

```csv
単語,日本語訳,例文,例文の日本語訳
こんにちは,こんにちは,こんにちは。,こんにちは。
```

- `VocabularySets/` はGitHubに同梱するCSVの置き場所です。
- アプリからインポートするCSVは**端末内に保存**され、GitHubにはアップロードされません。
- 星印もブラウザのIndexedDBに保存されます。アプリの削除・Webサイトデータ消去・端末変更で失われる可能性があるため、**CSV原本のバックアップ**を残してください。
- GitHub Pagesで同梱したCSVはインターネット上で公開されます。非公開の学習データは端末からインポートしてください。
- オフライン利用には、最初にオンラインでアプリを開き、Service Workerのキャッシュ作成が成功している必要があります。OSによるキャッシュ削除があれば再度通信が必要です。
