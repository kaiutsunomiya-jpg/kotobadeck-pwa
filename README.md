# たんたんご！ PWA v5 — 強調表示修正版

GitHub Pagesで利用できる単語学習アプリです。iPhoneホーム画面から起動できます。

## 今回の変更点

- **ホーム画面右上**にモルモットのアイコン画像を追加。
- **5列CSV**に対応（同梱100語すべての強調箇所を入力済み）。5列目「強調箇所」と例文で一致した最初の部分を**太字＋下線**で表示（単語一覧の下部パネル・テスト画面の両方）。従来の4列CSVも読み込み可能。
- **縦画面優先**：マニフェストで縦向きを指定、可能なブラウザで方向ロックを要求。iPhoneのような非対応環境では、横向き時にアプリ本体を回転して縦向きレイアウトを保持するCSSで対応。
- **単語一覧**で選択した単語が上側リストの最上部に来るよう自動スクロール。末尾の単語も対応。
- **テスト左下**に「前へ」ボタンを追加（前の単語の表面へ戻る）。
- 例文パネル上部の**横長バーを削除**。
- アプリ更新時も、元のIndexedDBデータベース名・バージョン・保存先を維持して、**各端末内のCSVと⭐復習登録を引き継ぐ**。

## GitHub上の既存アプリを更新する方法

1. ZIPを解凍。
2. 既存のGitHubリポジトリを開き、**同じリポジトリ、同じGitHub Pages URL**を維持して更新。
3. `index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest`、`icons/`、`VocabularySets/` などの中身を反映（`index.html`はリポジトリのルート）。
4. `main` ブランチにコミットするとPagesが再公開されます。アプリをオンラインで再読み込みすると新しいファイルが取り込まれます。Service Worker更新が反映されるまで、再起動・再読み込みが必要な場合もあります。

**重要**：このv5版には、ユーザーが添付した「第47回TOPIKⅡ_上級韓国語100単語(1)(2).csv」と**同じ5列データ（100語の強調箇所が全て記入済み）**を、従来の同梱ファイル名「第47回TOPIKⅡ_上級韓国語100単語(1).csv」で収録しました。従来の単語セットIDを維持し、既存の⭐データとの対応を保ちます。

GitHub上の**`VocabularySets/第47回TOPIKⅡ_上級韓国語100単語(1).csv`を必ずこのファイルで上書き**してください（ファイル名は変えないでください）。以前のv4同梱CSVは強調箇所が全100語空欄でした。`app.js`/`sw.js`だけ更新しても、CSVが古いままだと強調されません。

### 保存済みCSV・⭐について

- 旧版の `kotobadeck-local-sets` / `vocabulary-sets` / `review-flags` を継続利用します。アップデート処理やキャッシュ更新でこれらを削除しません。
- ローカルCSVは端末ごとに別々に保持されます。**別端末間の自動同期ではありません。**
- URLのドメイン・サイト構成を変更したり、ホーム画面アプリを削除したり、Safari/OSがサイトデータを消去すると、データが引き継がれない場合があります。**Webアプリのアイコンを削除し直す必要はありません。**
- IndexedDBは端末やOSの判断で消去される可能性があり、ブラウザだけでは絶対にデータの消失を防げません。**元のCSVは「ファイル」アプリやクラウドへバックアップしてください。**
- ⭐の登録はセットIDと単語・訳に基づき保存。登録済み単語のCSVファイル名や単語・訳を変更した場合、⭐が引き継がれないことがあります。

## 5列CSVの形式

1行目の見出しは**以下の順序**にします。

```csv
単語,日本語訳,例文,例文の日本語訳,強調箇所
담을 쌓다,"関係を断つ、距離を置く",그는 오랫동안 이웃과 담을 쌓고 지냈다.,彼は長年隣人と距離を置いて暮らしていた。,과 담을 쌓고
```

- 5列目「強調箇所」に入力した文字と、3列目「例文」の文字を**完全一致で照合**します。助詞や活用形を含めて指定できます。
- 最初に見つかった一致箇所のみ太字＋下線表示。同一文字列が複数ある場合も最初だけ。
- 空欄・不一致なら強調しません。**見出しを5列にする場合は全行を5列にすることを推奨します**。
- CSVはUTF-8（BOMあり/なし対応）。カンマ・改行・引用符をフィールドに含める場合は標準CSVの引用符ルールを使用。
- 同梱の `VocabularySets/第47回TOPIKⅡ_上級韓国語100単語(1).csv` は**100語すべてに強調箇所を入力済み**です。
- アプリ内の「CSVを追加」から読み込む5列CSVも強調されます。端末内CSVはGitHubにはアップロードされません。

## 縦画面固定について

iOS Safariのホーム画面PWAは、ネイティブSwiftアプリと違って**OSレベルの縦向きロックを確実に設定するAPIがありません**。本版は `orientation: portrait-primary` の指定と対応ブラウザ向けの方向ロックを行い、iPhone等では横向きに切り替わったときに画面内のUIを回転して**縦向きレイアウトを維持**する代替手段を採用しています。

OSのステータスバーやSafariのブラウザ自体を回転させない保証はありません。端末自体を確実に縦固定したい場合は、iPhoneの**「画面縦向きのロック」**をオンにしてください。

## 構成

```text
index.html            アプリ入口
app.js                CSV・一覧・テスト・⭐・画面制御
styles.css            UI・縦向き表示
sw.js                 オフラインキャッシュ（v5）
manifest.webmanifest  アイコン・アプリ名・縦向き希望
icons/                モルモットのアイコン3サイズ
VocabularySets/       デフォルト100語の5列CSV（強調箇所は空欄）
.nojekyll             GitHub Pages用
```

公開するアプリに登録したCSVデータはGitHub Pagesの公開リソースになります。非公開にしたい単語セットは、ホーム画面の「CSVを追加」から端末内へ読み込んでください。


## v5 強調が出ない場合

1. GitHubの `VocabularySets/第47回TOPIKⅡ_上級韓国語100単語(1).csv` を開き、1行目が `単語,日本語訳,例文,例文の日本語訳,強調箇所` で、2行目の末尾が `세련되어` になっているか確認。
2. 同じリポジトリの `index.html` / `app.js` / `styles.css` / `sw.js` をv5に更新し、GitHub Pagesのデプロイ完了を待つ。
3. PWAを閉じ、オンライン状態で再起動。必要に応じてSafariでページを再読み込み。アプリを削除する必要はありません。
4. ホーム画面で `第47回TOPIKⅡ_上級韓国語100単語(1)` と表示されている**同梱セット**を選択。別途「CSVを追加」で読み込んだ古い4列版のセットは更新されないため、その場合は5列版CSVを再追加してください。

※ Webブラウザのサイトデータ（IndexedDB）を削除しないでください。復習マークや端末内CSVを失う可能性があります。
